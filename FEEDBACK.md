# Feedback and conversation

Lizard is currently developed by Bhargav Koppula. This public journal is a place to follow the project's evolution and invite thoughtful conversation; it is not an open-source code-contribution project.

Feedback is welcome on:

- Product experience and usability.
- Feature ideas and observed bugs.
- Research questions about digital behaviour.
- Design choices and limitations.
- Technical discussion at a high level.
- Possible collaboration.

Please describe the context and the browser/product version when reporting an observation. Avoid sending session exports, real browsing histories, private notes or other sensitive personal data.

For a source-code review request or technical collaboration enquiry, contact **bhargavkoppula26@gmail.com**. Requests are considered individually and do not guarantee source access.

This repository does not invite pull requests that modify Lizard's private extension source. Suggestions to improve this public journal may be discussed with the creator.
