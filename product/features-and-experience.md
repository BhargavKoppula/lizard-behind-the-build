# Features and experience

This page describes the current published product at a user-facing level. It is not a substitute for the extension's private technical documentation, and it avoids claims about unverified behavior.

## Session choices

Lizard offers **Work**, **Reading** and **Video** sessions. A person chooses the context and can start a timed or open-ended session, pause and resume, or finish/stop it. The category tells the product which interpretation to present; it does not classify the user's mental state.

## Reviewing a session

The product includes a live session view, a timeline, completed-session history and simple pattern summaries. The timeline helps distinguish events from the later interpretation of a session. Pattern labels depend on the amount of stored experience and should be read as exploratory summaries, not statistical validation.

## Video and companion

For some sites, Lizard can observe compatible browser video-player behavior. Site/player compatibility is incomplete; playback evidence is not evidence that someone watched or understood the material. Lizzy is an optional companion character, not a measure of attention.

## User control

The published experience includes notifications and user-requested exports. The session intention field lets a person add their own context. This journal does not claim that the current package provides a user-facing reflection or notes editor; Store/privacy copy on that point is under owner review.

## Availability

The Chrome Web Store currently lists version **3.3.1**. This repository is the product journal only; it does not contain the extension download or implementation source. See [source access](../SOURCE_ACCESS.md).
