# Known limitations

## Activity is not attention

An interaction signal records an input-like event, not a person's attention or intent. Quiet users may be reading or thinking; highly active users may be distracted. Inactivity cannot be equated with disengagement.

## Reading context

Reading and planning can involve long quiet periods. Lizard does not know a person's comprehension, document position or task relevance from a session category. A Reading label is a user-selected context, not a detected cognitive state.

## Video compatibility

Video observations depend on what a browser page exposes. Some players or restricted contexts may not report compatible state. Retained tests include cases where player discovery occurred but recorded playback time stayed at zero. Playback also does not show that anyone watched, understood or learned from a video.

## Browser reliability

Browser extensions run within a lifecycle controlled by the browser. Suspension, restart, event delivery and differences between sites can affect the record. The project has not demonstrated every lifecycle or site scenario.

## Exploratory summaries

Timeline and pattern summaries depend on the signals, timestamps and sample available. They can omit context and should not be treated as research-grade measurements, validated confidence estimates or causal conclusions.

## Privacy and platform scope

Lizard is a browser extension and its user-facing permissions/privacy descriptions should be reviewed carefully. A locally stored session record is still personal data. Exported files can contain user-entered context and remain under the user's control outside the extension. Consult the current Chrome Web Store privacy information for the latest disclosures.

## Evidence boundary

A passing automated test shows that a controlled case passed. Manual tests show what happened in a particular browser and site. Chrome Web Store publication indicates Store acceptance, not that every technical scenario works or that the product is scientifically validated.
