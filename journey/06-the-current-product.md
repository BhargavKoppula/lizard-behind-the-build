# 6. The current product

The current published Chrome Web Store package is Lizard **3.3.1**. Its product language has moved away from promising to detect “focus” and toward helping a person look back at computer-based sessions.

The current experience offers:

- Work, Reading and Video session categories.
- Session start, pause/resume and finish/stop controls.
- A timeline and a history for reviewing completed sessions.
- Simple, sample-dependent pattern summaries.
- Session notifications and user-requested exports.
- An optional companion character, Lizzy.
- A session intention field for the user's own context.

These features organise limited observations; they do not state what the person attended to. A Timeline can show an event or estimate. A Pattern summary can describe a repeat in the stored records. Neither is a scientific result or a score of someone’s performance.

Some details remain uncertain. Retained browser QA reported Video tests in which playback time remained at zero. The Store's acceptance does not prove every site or browser scenario works. The project also has an unresolved mismatch between Store/privacy wording about reflections and the reviewed package's visible intention field; this public journal does not claim that a reflection-entry feature is available.

For the product's principles and caveats, see [tracking philosophy](../product/tracking-philosophy.md) and [known limitations](../product/known-limitations.md).
